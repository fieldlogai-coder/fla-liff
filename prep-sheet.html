FIELDLOG 準備シート

ご記入は10〜15分ほどです。分かる範囲でOK、あとからいつでも変更できます。

ご記入方法：この画面に直接入力できます。書いた内容はこのスマホ（パソコン）に自動で残るので、途中でやめても、あとで開けば続きから書けます。 書き終えたら、いちばん下の「この内容をLINEで送る」を押してください。記入済みのシートが、リンク1本で届きます。
運営に見せたくない区分は、区分の上の「自分でアプリに入れる（運営に送らない）」にチェックしてください。その区分は送られません。あとでアプリに直接入れられます。 行が足りないときは「＋ 行を追加」で増やせます。紙に手書きされる場合は、そのまま印刷してお使いください。
「自分でアプリに入れる」とは？（送る・送らないの違い）
運営に送る（チェックしない）自分でアプリに入れる（チェックする）
よい点運営が代わりに登録するので、手間がかかりません。入れ間違いも運営と一緒に確かめられますその区分の内容は、運営に届きません。LINEのトークにも残りません
気をつける点書いた内容は運営に届きます（登録のためだけに使い、ほかには使いません）社長（管理者）が自分でアプリに入れる手間がかかります。入れるまで、その区分を使う機能が動きません。入れ方で迷ったときは運営に聞くことになります（そのときも中身は見ずに説明します）

どちらを選んでも、アプリに入ったデータは、運営は中身を見ないお約束で扱います（くわしくは「データの取り扱いのお約束」）。

各区分にはおすすめを最初から選んであります。そのままで大丈夫です。変えたいところだけチェックを付け外ししてください。

① 会社情報 請求書に印字されます

✨ 入れると使えるようになること
  • 会社名・住所・電話・登録番号 → 請求書の発行元が自動で印字されます（インボイスの登録番号も）
  • 振込先 → 請求書に振込先が自動で印字されます
この区分は、自分でアプリに入れます

② 使う方 作業員の方も含めて全員

✨ 入れると使えるようになること
  • 請求書を作る方（事務など） → 社長以外の方も請求書を作れ、ダッシュボードを見られます
  • 職長・作業員の方 → LINEで登録して日報を出せます。日報の人工が請求書に自動で入ります
この区分は、自分でアプリに入れます
お名前役割請求書を作る
例）〇〇 太郎社長○
「請求書を作る」に○の方だけが、請求と経営の数字（ダッシュボード）を開けます。
作業員ごとの日給は、このシートには書かず、アプリの「設定」の作業員タブで管理者の方が入れてください（職人さんには見えず、運営にも送られません）。

③ 請求先（元請）ごとに 取引のある元請の数だけ

✨ 入れると使えるようになること
  • 会社名・締め日 → その元請の請求書が作れます。締め日で請求の期間が自動で決まります
  • 入金の条件 → ダッシュボードに入金予定・入金遅れが出ます
  • 請求書に必ず書く欄 → 工事番号・注文番号などの書き忘れを防げます
  • 指定の様式（＋請求書のExcel） → 今出している物と同じ形の請求書が作れ、PDFでメールに送る・スマホに保存できます
この区分は、自分でアプリに入れます
会社名締め日入金の条件請求書に必ず書く欄出し方・指定様式
例）△△工業25日締め翌月10日払い工事番号・注文番号メール／指定様式あり
入金の条件は「今月いくら入ってくるか」の計算に使います（例：末日締め・翌月末払い）。
請求書のExcel：元請ごとに、最近実際に出した請求書のExcelファイル（記入済み・1〜2か月分）を、このシートとは別にLINEかメールでお送りください。元請から配られた白紙の様式があれば、それもお願いします。FLAから出す請求書を、今お出しの物と全く同じ形にするために使います。

④ いま動いている現場

✨ 入れると使えるようになること
  • 現場名 → 日報と請求書で、その現場を選べます
  • 請負金額・工事名 → 請負の請求書で注文金額・出来高・残額が自動で計算されます。件名に工事名が入ります
この区分は、自分でアプリに入れます
現場名元請請負／常用請負金額（税抜）工事名（請求書の件名）
例）〇〇マンション改修△△工業請負3,000,000〇〇マンション改修工事

⑤ 常用（人工）の単価 元請に請求する単価・常用の請求をする場合

✨ 入れると使えるようになること
  • 工種ごとの終日・半日の単価 → 常用の請求は、人工を入れるだけで金額が出ます
この区分は、自分でアプリに入れます
工種元請終日の単価半日の単価（半額でない場合）
例）塗装△△工業22,00012,000

⑥ 経営の数字（ダッシュボード）のために ざっくりで構いません

✨ 入れると使えるようになること
  • 人工1人1日の原価 → ダッシュボードに人件費と粗利が出ます
  • 会計年度の開始月 → 「今期」の売上や利益が、自社の年度で集計されます
  • 利益率が低いと感じるライン → 利益が出ていない現場を、ダッシュボードが知らせます
この区分は、自分でアプリに入れます
日報の人工 × この原価で人件費を自動計算し、現場ごとの利益率を出します。作業員ごとの日給を入れた方は、その日給で計算します。金額は後からいつでも変更でき、変更すると過去分も計算し直します。
